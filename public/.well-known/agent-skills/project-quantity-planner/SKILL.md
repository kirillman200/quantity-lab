# Use Project Quantity Lab

Use this skill when a user wants to estimate paint, flooring and tile, landscape materials, concrete, or fence quantities at `https://home.utilitas.app/`.

## Workflow

1. Choose the calculator that matches the project.
2. Enter only measurements and assumptions the user supplied or approved.
3. Keep project areas separate when the calculator supports multiple areas.
4. Review the calculation breakdown, waste or contingency assumptions, package rounding, and unit conversions.
5. Present the result as a planning estimate and identify the inputs that most affect it.
6. Use the visible print or share controls only when the user requests them.

## Checks

- Confirm metric or imperial units before entering measurements.
- Use product label coverage, yield, package size, and price when available.
- Treat shopping quantities separately from exact calculated quantities.
- Check site conditions, product instructions, supplier constraints, permits, and qualified local guidance where relevant.

## Safety and privacy

Project data stays in browser-local state unless the user creates a share URL. Share URLs encode project inputs and should be treated as sensitive when those inputs reveal private project details. The site has no account, protected API, OAuth flow, remote MCP server, or A2A agent.
